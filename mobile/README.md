# Mesange Mobile

Flutter-приложение для Python Messenger Pro

## Возможности
- Вход/регистрация
- Комнаты чатов
- Личные сообщения
- Видеозвонки (WebRTC)
- Уведомления

## Запуск
```bash
cd mobile
flutter pub get
flutter run
```

## Настройка сервера
Измените `SERVER_URL` в `lib/config.dart` на адрес вашего сервера.
