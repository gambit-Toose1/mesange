# Messenger Project

Современный кроссплатформенный мессенджер с поддержкой веб, десктоп и мобильных клиентов.

## 🚀 Возможности

- **Личные чаты** - общение между пользователями один на один
- **Групповые комнаты** - создание общих чатов для команд
- **Администрирование** - расширенные права для модерации
- **Статус сети** - улучшенное отображение состояния подключения
- **Безопасность** - JWT аутентификация и защита данных
- **Кроссплатформенность** - работа на всех популярных платформах

## 📁 Структура проекта

```
├── server.py           # Серверная часть (Python + aiohttp)
├── database.py         # Работа с базой данных
├── models.py           # Модели данных SQLAlchemy
├── desktop.py          # Десктопный клиент (PyQt6)
├── index.html          # Веб-интерфейс (HTML/CSS/JS)
├── mobile/             # Мобильное приложение (Flutter)
│   ├── lib/
│   │   ├── main.dart
│   │   └── config.dart
│   └── pubspec.yaml
├── .github/
│   └── workflows/
│       └── build-apk.yml  # CI/CD для сборки APK
└── README.md           # Документация
```

## 🛠 Технологии

### Сервер
- **Python 3.x**
- **aiohttp** - асинхронный веб-сервер
- **SQLAlchemy** - ORM для работы с БД
- **PyJWT** - токены аутентификации
- **SQLite** - база данных

### Веб-клиент
- **HTML5/CSS3** - современный интерфейс
- **Vanilla JavaScript** - без зависимостей
- **WebSocket** - реальное время

### Десктоп-клиент
- **Python 3.x**
- **PyQt6** - графический интерфейс
- **websocket-client** - подключение к серверу

### Мобильное приложение
- **Flutter 3.24+**
- **Dart**
- Платформы: Android, iOS

## 🚀 Быстрый старт

### Запуск сервера

```bash
# Установка зависимостей
pip install sqlalchemy aiohttp pyjwt

# Запуск сервера
python server.py
```

Сервер запустится на `http://localhost:8000`

### Веб-клиент

Просто откройте `index.html` в браузере или используйте локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/index.html`

### Десктоп-клиент

```bash
# Установка зависимостей
pip install PyQt6 websocket-client

# Запуск
python desktop.py
```

### Мобильное приложение

```bash
cd mobile

# Установка зависимостей
flutter pub get

# Запуск в режиме разработки
flutter run

# Сборка APK
flutter build apk --release
```

## 🔧 API Документация

После запуска сервера документация доступна по адресу:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc**: `http://localhost:8000/redoc`

### Основные эндпоинты

#### Аутентификация
- `POST /auth/register` - регистрация нового пользователя
- `POST /auth/login` - вход в систему

#### Пользователи
- `GET /users/me` - информация о текущем пользователе
- `GET /users` - список всех пользователей (для личных чатов)

#### Чаты
- `GET /rooms` - список комнат
- `POST /rooms` - создание новой комнаты
- `GET /rooms/{room_id}/messages` - история сообщений
- `POST /rooms/{room_id}/messages` - отправка сообщения

#### Администрирование
- `GET /admin/stats` - статистика системы
- `POST /admin/users/{user_id}/toggle-admin` - назначение/снятие прав админа

Улучшенная система отображения статуса подключения:
- 🟢 **Онлайн** - стабильное соединение
- 🟡 **Переподключение** - попытка восстановления связи
- 🔴 **Оффлайн** - соединение потеряно
